# 50 Años de Amor – Website

## Ordnerstruktur
- `index.html` – Website-Inhalt
- `style.css` – Retro-Farben und Gestaltung
- `script.js` – JavaScript
- `assets/photos/` – alle persönlichen Bilder

## Bildnamen – bitte genau so verwenden

**Startseite und Erinnerungen**
- `mama-portrait.jpg` – grosses Foto auf der Startseite
- `baby-photo.jpg` – Babyfoto
- `childhood-photo.jpg` – Kindheitsfoto
- `family-photo.jpg` – Familienfoto
- `friends-photo.jpg` – Foto mit Freunden/Familie

**Reise-Collage**
- `mexico-trip.jpg` – Mexiko-Reise
- `beach-trip.jpg` – Strandferien
- `city-trip.jpg` – Städtereise
- `adventure-trip.jpg` – weitere Reise oder Abenteuer

Alle Bilder gehören in `assets/photos/`.

## So fügst du Bilder hinzu
1. Öffne dein GitHub-Repository.
2. Öffne `assets` und danach `photos`.
3. Klicke auf **Add file → Upload files**.
4. Ziehe deine Bilder hinein oder wähle sie über **choose your files** aus.
5. Achte darauf, dass die Dateinamen exakt wie oben geschrieben sind.
6. Klicke auf **Commit changes**.

Du kannst auch weniger Bilder verwenden. Für nicht hochgeladene Fotos zeigt die Website einen farbigen Platzhalter.

## Website-Dateien aktualisieren
Lade `index.html` und `style.css` aus diesem ZIP neu in dein Repository hoch und bestätige mit **Commit changes**. `script.js` und `README.md` bleiben kompatibel.
