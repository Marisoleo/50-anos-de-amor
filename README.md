# 50 Años de Amor

Eine persönliche Geburtstagswebsite zum 50. Geburtstag – gebaut mit HTML, CSS und JavaScript.

## Dateien
- `index.html` – Inhalt der Website
- `style.css` – Design und Animationen
- `script.js` – interaktive Funktionen
- `assets/photos/` – hier kommen die Fotos hinein
- `assets/music/` – optionaler Ordner für Musik

## Fotos einfügen
Lege deine Bilder in `assets/photos/` und verwende genau diese Dateinamen:

- `hero.jpg` – grosses Foto auf der Startseite
- `baby.jpg` – Babyfoto
- `childhood.jpg` – Kindheit
- `teenage.jpg` – Jugend
- `young-adult.jpg` – junge Erwachsene
- `today.jpg` – aktuelles Foto
- `memory-1.jpg` bis `memory-4.jpg` – Galerie

Du kannst JPG-, PNG- oder WebP-Bilder verwenden. Wenn du ein anderes Format verwendest, ändere auch den Dateinamen in `index.html`.

## Lokal testen
Öffne `index.html` im Browser. In VS Code kannst du auch die Erweiterung **Live Server** verwenden.

## Auf GitHub Pages veröffentlichen
1. Erstelle auf GitHub ein neues Repository, zum Beispiel `50-anos-de-amor`.
2. Lade alle Dateien und den Ordner `assets` hoch.
3. Öffne im Repository **Settings → Pages**.
4. Bei **Build and deployment** wähle **Deploy from a branch**.
5. Wähle `main` und `/ (root)`, dann **Save**.
6. Nach kurzer Zeit zeigt GitHub Pages deine Website-Adresse an.

## Privatsphäre
GitHub Pages ist normalerweise öffentlich erreichbar. Ein geheimer Link ist kein Passwortschutz. Lade deshalb keine Fotos oder persönlichen Informationen hoch, ohne dass die abgebildeten Personen damit einverstanden sind. Für wirklich private Fotos eignet sich ein lokaler Betrieb oder ein Hosting mit echtem Passwortschutz besser.
